# Security Policy

## Supported versions

Lucent Raw is in testing. Only the newest tester build (0.1.0-testN) gets fixes; older tester builds do not. Please update to the newest build before reporting.

## Reporting a problem

Email bbotnicsindustries@gmail.com with:

- the build number (Preferences > About, or the installer's file name),
- what you did and what happened,
- a file that shows the problem, if you can share one.

Please do not post security problems in public. Do not send your photos unless asked.
